# RemoteKeycard-LABAPI
I made this for my server but decided to release the LabAPI version publicly on this branch (also the code might be horrible, you can judge if you want)

Issues:
- Warhead is still not done yet because I only did the basic stuff for now.
- If you have two keycards and one of them is of a higher permission level, it will still take the first keycard (example: you have janitor and 05 both in inventory, you cannot use remote keycard on anything that requires a 05 because it takes the janitor card instead).
- There might be other bugs that I either forgot to include or I haven't tested for them, if you find any of them then make a issue.
